7. FASE BETA: Statistiche Globali, Personalizzazione e Widget

7.1 Sviluppatore 1: UI Nuove Funzionalità

  • 7.1.1 UI Statistiche Globali: Sviluppo nuova sezione nel menù per mostrare i "Record Personali" (Velocità max assoluta, Media generale, Km totali, Tempo totale, Viaggio più lungo).
  • 7.1.2 UI Personalizzazione Auto: Schermata per selezionare il logo della propria auto (SVG) e il colore preferito per il cursore sulla mappa.
  • 7.1.3 (Bonus) Widget Spotify: Creazione di un overlay fluttuante per mostrare brano e copertina durante il viaggio.

7.2 Sviluppatore 2: Aggregazione Dati e Backend BETA

  • 7.2.1 Query Aggregazione (Record Personali): Creazione di una funzione RPC su Supabase o logica lato client per calcolare somme (SUM) e record (MAX) basati sull'intero storico dell'utente.
  • 7.2.2 DB Preferenze: Aggiornamento tabella users per poter salvare in cloud l'icona dell'auto e il colore scelto, così da mantenerli tra vari dispositivi.
  • 7.2.3 (Bonus) API Spotify: Setup dell'autenticazione OAuth con Spotify e polling dell'endpoint /me/player/currently-playing.

8. FASE 8: Classifiche e Profilo Utente

8.1 Sviluppatore 1: UI Classifiche e Profilo

  • 8.1.1 Classifica Generale: UI per mostrare la tabella degli utenti con Posizione, Nickname, Avatar e Categoria.
  • 8.1.2 Filtri Classifica: UI per filtrare la leaderboard in base a "Distanza Totale", "Velocità Massima", ecc.
  • 8.1.3 Profilo Utente: Sezione nelle impostazioni per modificare Nickname e fare l'upload dell'Immagine Profilo.

8.2 Sviluppatore 2: Backend Classifiche e DB Utenti

  • 8.2.1 Aggiornamento DB Users: Aggiunta colonne per nickname e avatar_url.
  • 8.2.2 Query Classifica: Creazione endpoint o funzione Supabase per scaricare le statistiche aggregate di tutti gli utenti, ordinabili per metrica.
